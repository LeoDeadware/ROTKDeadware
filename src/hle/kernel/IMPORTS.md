| range | use |
|---|---|
| 0x00010000 – image end (0x5598C0) | XBE, mapped by the loader (all sections, also non-preload) |
| 0x00600000 – 0x7EF00000 | NtAllocateVirtualMemory, thread stacks (64 KB granularity) |
| 0x7F000000 – 0x7FFFFFFF | left to the runtime (x86recomp thunks/TEB/PEB) |

| 0x8FF00000 – 0x8FF10000 | data exports |
| 0x90000000 – 0x98000000 | kernel pool: ExAllocatePool, KPCR/KTHREAD, KEVENTs of Nt handles |
| 0xFD000000 – 0xFE020000 | runtime: rotk_hle_alloc, kernel thunks 0xFE000000 + ord·16, host thunks |

## Threads, TLS, IRQL
- One Xbox KPCR per host thread at `fs_base` (NtTib, SelfPcr, Prcb, Irql @0x24, CurrentThread @0x28).
- `TlsData = NtTib.StackBase − TlsDataSize` exactly: XAPI writes `*AddressOfIndex = TlsDataSize / −4`
  (−5 for default.xbe, TlsDataSize 0x14) and reads `[fs:[4] + idx·4]`. Its thread startup
  (0x111D6D) copies the template; the kernel only places the block.
- DPCs run on one service thread at DISPATCH_LEVEL; DISPATCH_LEVEL elsewhere = a global recursive lock.

## File system
- `\??\D:` is pre-linked to `\Device\CdRom0`; XAPI links T:, U:, Z: itself via IoCreateSymbolicLink.
- Disc = `ROTK_MODS` / `cfg.mods_dirs` (':'-separated, first wins; default `$ROTK_DATA/mods/uk` whenever
  it exists: it only overrides the _UK slot, so the game's picker can switch to it) over `cfg.disc_dir` (default `$ROTK_DATA/game/extracted`). Case-insensitive.
- HDD = `<data>/hdd/partition{1,3,4,5}`; `<data>` = `~/Library/Application Support/ROTKPort/<ROTK_PROFILE|default>`.
- XAPI reads its cache-partition table at `\Device\Harddisk0\partition0` + 0x800 → `<data>/hdd/partition0.bin`.
- **Z: cache off by default**: the cache partition reports 0 free bytes, so the game's
  `Z:\potterfilecache` setup (FUN_00017080 needs > 0x5000F free) disables itself and every read goes to
  `D:` — i.e. through the mods layer. `ROTK_ZCACHE=1` reports free space (cache copies would then bypass mods).

Language slot logic (FUN_00011290): XGetLanguage English + XGetGameRegion North America → `_USA`
(mask 2); English + other region → `_UK` (mask 1); de/fr/es/it → their slots. Refresh variable
0x51E088 = 60.0 because the AV region is NTSC-M (video standard ≠ 3 = PAL).

## Open points
- APCs (I/O completion routines, alertable waits) are not delivered; the game's XAPI paths pass none.
- Mutants/semaphores have no creating import; waits handle their headers generically.
- RtlRaiseException/RtlUnwind follow x86recomp's model (lifted `resume` sites for `__except`).
- XboxHardwareInfo flags, keys: plausible values, not dumped from a console.
